**不是套通用模型壳,每一帧都为电商场景调过**。

### 1️⃣ 电商带货模块 · 商品图 → 带货视频(V1 营销成片引擎)

**端到端替代"商品视频制作团队"的营销 Agent** —— 从理解商品到投放成片全自动化,保留商品细节一致性,可直接投流。

| 输入 | 自动完成 |
|---|---|
| 📦 **商品名 + 商品主图**(模特图可选) | 智能脚本 + 分镜 / 热点话术 + 流行运镜 / 数字人 + 唇形同步 / 版权素材自动匹配 |

**两种生成模式**:
- 🤝 **有模特** —— 商品图 + 模特图融合
- 📦 **无模特** —— 只用商品图

![电商带货工作台](./screenshots/sp-ecommerce-ui.png)

### 2️⃣ 智能视频模块 · 一句话变 9:16 短视频(V1 视频合成引擎)

**无需脚本、无需剪辑、无需镜头语言** —— 输入文字描述,引擎自主拆分镜、生成画面、配音、加字幕,几分钟交付一条可直接发布的成品视频。

| 模式 | 用法 |
|---|---|
| ✨ **有参考** | 复刻参考视频 / 图的风格(镜头语言、色调、节奏) |
| 🎬 **无参考** | 完全文生视频(`mode=video-no-ref`) |

**16 个高频赛道模板**:健身 / 美食 / 亲子 / 知识 等(完整列表以演示站当期为准)。

## 💼 典型场景

### 场景 1 · 单 SKU 带货视频(电商代运营)

每天要出几十条带货视频,从 2 小时压到 < 3 分钟:

1. 拿到客户商品实物图,先 rembg / PS 抠白底
2. 进电商带货工作台,选「有模特 / 无模特」生成模式
3. 填商品名 + 上传白底图(有模特模式再加模特图)
4. 选画幅 9:16 + 音色按品类
5. 提交 → 60 秒后预览 → **立刻下载 mp4(1 小时内必下)**
6. 上传抖音 / 视频号 / 小红书

### 场景 2 · MCN 矩阵号差异化铺货

12 个矩阵号同一 SKU 避免限流:

1. 电商带货模块多次跑同一商品(Agent 每次自动出不同脚本风格),铺 4-6 个号
2. 智能视频模块用一句话 prompt 出差异化内容,铺剩余 6-8 个号
3. 数字人 / 音色 / 字幕样式按账号人设固定差异化
4. 风格漂移度足够大,算法识别不出同号

### 场景 3 · 老板没空出镜的小商家

数字人 + 11 中文音色 + 多方言配音 + 唇形同步直接替代真人。

### 场景 4 · 节日营销批量出货

智能视频模块 + 节日模板 → 不同品类各出节日营销片 → 一周铺满矩阵号。

## ❓ FAQ

<details>
<summary><b>Q:电商带货模块需要写 prompt 吗?</b></summary>

**不需要写 prompt**。输入字段是商品名 + 商品主图(模特图按"有模特 / 无模特"模式可选)。Agent 端到端自动理解商品 / 写脚本 / 调镜头 / 生成。
</details>

<details>
<summary><b>Q:智能视频模块需要 prompt 吗?</b></summary>

**有参考模式**:可贴参考视频或商品 / 模特图,复刻风格。
**无参考模式**:`mode=video-no-ref`,一句话 prompt 完全文生视频。
</details>

<details>
<summary><b>Q:两个模块怎么选?</b></summary>

- **有商品主图 + 想要带货脚本 / 商品上架视频** → 电商带货模块
- **只有文案 / 创意 / 想出内容向视频** → 智能视频模块
</details>

<details>
<summary><b>Q:为什么生成的视频 1 小时就失效?</b></summary>

**服务端预览链接 1 小时内有效**,为节省服务端存储。**必须及时下载到本地**,本地 mp4 无时效。
</details>

<details>
<summary><b>Q:电池怎么扣?</b></summary>

提交任务时按你选的最大时长预扣,按真实秒数 actual_cost 多退少补。**失败任务全额退电池**,自动退。
</details>

<details>
<summary><b>Q:产出视频可以商用吗?</b></summary>

可以,所有产出视频明确商用授权。内置千万级版权素材库 AI 自动匹配,**所有素材已购版权**,零版权风险。
</details>

<details>
<summary><b>Q:数字人形象能商用吗?</b></summary>

能。商用级数字人形象库 + 多方言配音 + 唇形同步,产出明确可商用。
</details>

<details>
<summary><b>Q:一键多平台发布上线了吗?</b></summary>

**即将上线**(产品路线图),目前需要下载 mp4 手动上传到抖音 / 视频号 / 淘宝 / 小红书。
</details>

<details>
<summary><b>Q:支持哪些支付方式?</b></summary>

微信扫码到账。
</details>

<details>
<summary><b>Q:适合什么样的团队?</b></summary>

- ✅ 电商代运营公司(日产几十条带货视频)
