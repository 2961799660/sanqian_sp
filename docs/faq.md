# 三千AI电商工作台 · 常见问题

## 〇、产品形态

**Q:电商带货模块需要写 prompt 吗?**
A:**不需要**。输入字段只有两个 —— 商品名 + 商品主图(模特图可选),**没有 prompt 输入框**。Agent 端到端自动理解商品 / 写脚本 / 调镜头 / 生成。

**Q:智能视频模块需要写 prompt 吗?**
A:**需要一句话 prompt**(`mode=video-no-ref`)。覆盖痛点开场 / 节日广告 / 产品展示 / 街拍 / 搞笑等场景。

**Q:两个模块怎么选?**
A:
- 有商品主图 + 想要带货脚本 / 商品上架视频 → **电商带货模块**
- 只有文案 / 创意 → **智能视频模块**

---

## 一、商用授权

**Q:产出视频可以商用吗?**
A:可以,所有产出视频明确商用授权。

**Q:生成的视频有版权吗?**
A:产出视频版权属用户,商用合规。内置千万级版权素材库 AI 自动匹配,**所有素材已购版权**,零版权风险。

**Q:数字人形象能商用吗?**
A:能。商用级数字人形象库 + 多方言配音 + 唇形同步,产出明确可商用。

**Q:可以基于产出做训练集再训练同类模型吗?**
A:不可以。禁止用产出做训练集喂同类视频生成模型。

## 二、电池与计费

**Q:电池怎么扣?**
A:提交任务时按你选的最大时长预扣,生成完按真实秒数算 actual_cost,**多退少补**。

**Q:失败任务怎么算?**
A:**失败任务全额退电池**,系统自动,无需申诉。

**Q:电池余额可以退现吗?**
A:一般不退现。可继续消耗,或咨询微信 aigc5256 转赠。

**Q:能开发票吗?**
A:可以,联系微信 aigc5256(普票 / 专票均可)。

**Q:支持哪些支付?**
A:微信扫码到账。

## 三、视频时效与下载

**Q:为什么生成的视频 1 小时就失效?**
A:**服务端预览链接 1 小时内有效**,设计上是为了节省服务端存储。**必须及时下载备份到本地**,下载后的 mp4 文件本地保存无时效限制。

**Q:下载的视频可以二次编辑吗?**
A:可以。下载后的 mp4 是标准文件,导入剪映 / Premiere / CapCut 二次编辑无限制。

**Q:能批量下载吗?**
A:Web 端支持单个下载,批量下载咨询微信 aigc5256 或走 API。

## 四、技术能力边界

**Q:支持哪些视频时长?**
A:廉价档以 30 秒为主,具体时长上限以演示站当期为准。

**Q:支持哪些画幅?**
A:按模块不同 —— **电商带货模块** 3 种(9:16 / 1:1 / 16:9);**智能视频模块** 4 种(9:16 / 16:9 / 4:3 / 3:4)。

**Q:中文音色有几种?**
A:**11 种**,覆盖男女老幼。完整列表见 [`product.md`](./product.md) 技术内核章节。

**Q:支持多方言吗?**
A:数字人配音支持多方言。

**Q:能复刻参考视频风格吗?**
A:能。**风格保留功能**复刻参考视频的镜头语言、色调、节奏,一比一移植。

**Q:领域模板有哪些?**
A:**16 个高频赛道模板**:健身 / 美食 / 亲子 / 知识 等(完整列表以演示站当期为准)。

**Q:能一句话出多个风格吗?**
A:能。V1 营销成片引擎**单次指令多风格并行**,一次出 4 个风格(促销 / 品牌 / 节日 / 数字人口播)供挑。

## 五、发布与分发

**Q:一键发布到抖音 / 视频号 / 淘宝 / 小红书什么时候上?**
A:**即将上线**(产品路线图),目前下载 mp4 手动上传。

## 六、数据安全

**Q:我的数据 / 视频会被用来训练吗?**
A:具体见演示站隐私协议。一般来说生成内容归用户所有,平台不二次用于训练。

**Q:商品图上传安全吗?**
A:商品图存储在私有 Bucket,生成完任务后按隐私协议保留期清理。

## 七、对比其他工具

**Q:跟通用文生视频工具 / Sora / Veo 比怎么样?**
A:见 [`product.md`](./product.md) 第八章"对比同类工具"。简要:
- **海外创意视频工具**(Sora / Veo 等):创意强,但单价高 + 非电商场景特调 + 国内访问慢
- **通用国内文生视频工具**:底模质量好,但通用模型无电商语义先验,要拼配音 / 字幕 / 素材库多个工具
- **三千AI 电商**:专为电商调过,商用数字人 + 千万级版权素材 + 16 领域模板,国内访问稳

**Q:跟手剪(剪映等)比?**
A:剪映自由度高但单条 1-3 小时人工。三千AI 电商 **60 秒级出片**,适合批量出货 / 矩阵号场景。
