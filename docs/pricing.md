# 三千AI电商工作台 · 计费说明

## 计费机制

**电池制**,按真实使用扣费。**具体单价 + 套餐价格以演示站当期为准**。

## 扣费规则

1. **提交任务时按你选的最大时长预扣**
2. 生成完成按真实秒数算 actual_cost
3. **多退少补**
4. **失败任务全额退电池**
5. 所有扣费 / 退款都在「我的钱包」流水里查

## 新用户体验

- **手机号注册即送 100 电池**
- 可免费体验 **廉价档 30 秒视频**(具体引擎 / 风格选择以演示站为准)

## 套餐档位

演示站提供多档充值套餐,主要差别在:
- 基础电池数
- 赠送电池(套餐越大赠送比例越高)
- 适合的团队规模(个人 / 小团队 / 标准创作团队 / 企业团队)

**具体套餐对比和单价以演示站当期为准** → <https://sp.zijie.lol/>

## 不同任务的消耗参考

电池消耗按视频时长 + 引擎档位 + 增值选项三个维度计算:

| 维度 | 影响 |
|---|---|
| **视频时长** | 主因 — 60s 视频 ≈ 2 倍 30s 视频电池消耗 |
| **引擎档位** | 廉价档 / 标准档 / 旗舰档,差价线性 |
| **增值选项** | 数字人口播 / 多方言配音 / 4K 输出 等按需叠加 |

**具体单价以演示站当期为准**。

## 支付方式

## 退款政策
