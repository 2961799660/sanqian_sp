## 第 2 步 · 选模块(按场景分)

平台两个模块按场景分,选错就出错:

### 模块 1 · 电商带货模块(推荐 · 真零门槛)

| 你的情况 | 选这个 |
|---|---|
| 有商品主图(或模特图) | ✅ |
| 想要带货脚本 / 商品上架视频 | ✅ |
| 不想写 prompt(只想填商品名) | ✅ |

**输入只有两个字段**:
- 商品名
- 商品主图(模特图可选)

**没有 prompt 输入框**。提交后 Agent 端到端自动:理解商品 → 写脚本 → 调镜头 → 生成。

最快 60 秒生成,可选 **15 / 30 秒** 带货成片。

### 模块 2 · 智能视频模块

| 你的情况 | 选这个 |
|---|---|
| 只有文案 / 创意,没有商品图 | ✅ |
| 想要痛点开场 / 节日广告 / 街拍 / 搞笑等场景视频 | ✅ |
| 愿意写一句话 prompt | ✅ |

模式:`mode=video-no-ref`(纯文生视频)。

---

## 第 3 步 · 电商带货模块工作流(零门槛)

### 第 3.1 · 上传商品主图

直接拖拽商品实物图到上传框。**建议先白底处理**(rembg / PS / 在线工具抠白底),杂乱背景会干扰 Agent 抽商品特征。

### 第 3.2 · 填商品名

```
✅ "复古黄铜壁灯 · 工业管道造型"
✅ "减脂苹果干 · 0 添加糖"
✅ "羊羔毛机车皮衣 · 棕色 · 秋冬款"

❌ "壁灯"(太抽象,Agent 难抽特征)
❌ "好看的衣服"(纯形容,无信息)
```

**就这两个字段**。**不需要写 prompt**。

### 第 3.3 · 提交 → Agent 端到端自动

提交后 Agent 自动:
- 理解商品(从图 + 名字提取材质 / 类目 / 卖点)
- 写脚本(按卖点 / 痛点 / 场景三段结构)
- 调镜头(选合适运镜 / 景别)
- 生成 15 / 30 秒 9:16(可选 1:1 / 16:9)成片(含配音 + 字幕 + 配乐)

**最快 60 秒**。

---

## 第 4 步 · 智能视频模块工作流(一句话出片)

### 第 4.1 · 写一句话 Prompt

公式:`[人物 / 场景] + [动作 / 反应] + [画面氛围] + [画幅 + 平台风格]`

**真实案例**(从首页 prompt 库抠):

```
亚洲女生穿绿色运动背心站在阳光客厅捂肚子苦恼对镜头说"减脂期嘴馋怎么办",
画面下方浮出种草字幕,9:16 竖屏抖音种草风,柔和顶光自然氛围。
```

### Prompt 5 个写作要点

1. **先画面后台词**
2. **必带平台调性词**:`9:16 抖音种草风` / `杂志感构图` / `测评风格`
3. **加光线描述**:`柔和顶光` / `逆光` / `胶片颗粒感`
4. **加运镜词**:`慢推近` / `环绕运镜` / `定格特写`
5. **加情绪 / 反差**:`捂肚子苦恼` / `回眸轻笑`

## 第 5 步 · 选画幅 + 音色

### 画幅(按模块分)

- **电商带货模块**:9:16 / 1:1 / 16:9(3 种)
- **智能视频模块**:9:16 / 16:9 / 4:3 / 3:4(4 种)

| 画幅 | 适用 |
|---|---|
| **9:16** | 抖音 / 视频号 / 快手 / 小红书 视频帖 |
| **16:9** | B 站 / YouTube / 公众号视频 |
| **1:1**(仅电商带货) | 商品主图视频 / 朋友圈 |
| **4:3**(仅智能视频) | 淘宝详情页 |
| **3:4**(仅智能视频) | 京东详情页 / 小红书图文混排 |

### 中文音色(11 种)

按品类选 1 个调性匹配的:

- **女声 · 治愈** → 母婴 / 生活方式
- **女声 · 活泼** → 美食 / 美妆 / 服饰
- **女声 · 专业** → 美妆评测 / 知识科普
- **男声 · 沉稳** → 数码 / 商品展示
- **男声 · 搞笑** → 段子 / 反差脚本
- **童声** → 母婴 / 儿童用品
- 其他 5 种按品类选
