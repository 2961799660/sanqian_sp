# 三千AI电商工作台 · 完整产品介绍

## 一、产品定位

**给做电商的人,一个真零门槛的 AI 视频工作台 —— 连 prompt 都不需要写**。

适用人群:

- **电商运营 / 代运营**:商品图 → 带货视频批量自动出货
- **MCN 矩阵号操盘手**:多账号 / 多风格短视频日产
- **品牌方电商团队**:节日促销 / 新品发布 / 数字人口播
- **小商家 / 老板出镜号**:数字人替代真人出镜
- **跨平台铺货团队**:抖音 / 视频号 / 淘宝 / 小红书 多端铺货

## 二、两个模块详解

### 模块 1 · 电商带货模块 · 真零门槛

**这是产品最大的差异点 —— 不需要写 prompt**。

| 维度 | 描述 |
|---|---|
| **生成模式** | **有模特**(商品图 + 模特图融合)· **无模特**(只用商品图) |
| **输入字段** | **商品名称** + **商品主图** + **模特图**(有模特模式必填) |
| **没有 prompt 输入框** | Agent 端到端自动:理解商品 → 写脚本 → 调镜头 → 生成 |
| **画幅** | **9:16 / 1:1 / 16:9** 三选一 |
| **时长** | **15 秒 / 30 秒** 二选一 |
| **AI 出片时间** | 最快 60 秒(非视频时长) |
| **适用场景** | 商品上架视频 / 直投流广告 / 详情页视频 / 矩阵号铺货 |

**对比手剪流水**:

```
手剪:  脚本(10min) → 拍 / 找素材(20min) → 剪映粗剪(30min)
       → 字幕配音 BGM(20min) → 调色出品(15min)
       = 单条 60 秒视频 1-2 小时

电商带货模块:商品名 + 主图 → 60 秒后出 15/30 秒成片
       = 单条几乎零人工
```

**对比通用文生视频工具**:通用工具需要你写完整脚本 + 镜头描述,**等于把脑子环节都留给运营**。电商带货模块**直接把脑子环节也替代了**,这是核心差异。

### 模块 2 · 智能视频模块 · 一句话出片

| 维度 | 描述 |
|---|---|
| **生成模式** | **有参考**(复刻参考视频 / 图的风格)· **无参考**(纯文生视频 `mode=video-no-ref`) |
| **输入字段** | 视频描述(≤ 500 字)+ 参考素材(参考视频 ≤ 200MB ≤ 3 分钟 / 参考图 ≤ 20MB · 有参考模式必填) |
| **画幅** | **9:16 / 16:9 / 4:3 / 3:4** 四选一 |
| **时长** | **15 秒 / 30 秒 / 60 秒** 三选一 |
| **AI 出片时间** | 60 秒级 |
| **覆盖场景** | 痛点开场 / 节日广告 / 产品展示 / 街拍 / 搞笑 等 |

**真实案例 prompt**(直接从演示站抠的):

```
亚洲女生穿绿色运动背心站在阳光客厅捂肚子苦恼对镜头说"减脂期嘴馋怎么办",
画面下方浮出种草字幕,9:16 竖屏抖音种草风,柔和顶光自然氛围。
```

**Prompt 5 个写作要点**:

1. **先画面后台词**:画面要素写在前,镜头语言 / 配音文案放后
2. **必带平台调性词**:`9:16 抖音种草风` / `杂志感构图` / `测评风格`
3. **加光线描述**:`柔和顶光` / `逆光` / `胶片颗粒感`
4. **加运镜词**:`慢推近` / `环绕运镜` / `定格特写`
5. **加情绪 / 反差**:`捂肚子苦恼` / `回眸轻笑` / `叹气下一秒...`

完整 prompt 库见 [`../examples/prompts.md`](../examples/prompts.md)。

## 三、技术内核 · 自研多模态视频引擎 V1

不是套通用模型壳。**每一帧都为电商场景调过**。

### 3.1 多模态融合

文本、图像、参考视频统一编码,跨模态语义对齐。**不是简单的图生视频**。

### 3.2 风格保留

复刻参考视频的镜头语言、色调、节奏 —— **一比一移植到你的内容**。同一品牌长期出片可保持风格一致。

### 3.3 电商语义

内置电商内容生产先验,自动适配 **卖点 / 痛点 / 场景三段结构**。

举例:输入"减脂苹果干" → 系统自动产出:
- **痛点开场**:减脂期嘴馋怎么办
- **卖点中段**:0 添加糖 / 低卡 / 真实苹果
- **场景结尾**:办公室零食柜 / 健身后补给

### 3.4 中文 TTS 一体

不用单独跑配音工具。**11 种中文音色**覆盖男女老幼,一键应用。

按品类推荐音色:

| 品类 | 推荐音色 |
|---|---|
| 母婴 / 生活方式 | 女声 · 治愈 |
| 美食 / 美妆 / 服饰 | 女声 · 活泼 |
| 美妆评测 / 知识科普 | 女声 · 专业 |
| 数码 / 商品展示 / 品牌宣讲 | 男声 · 沉稳 |
| 段子 / 反差脚本 | 男声 · 搞笑 |
| 母婴 / 儿童用品 | 童声 |

## 四、能力矩阵

### 4.1 画幅模式(按模块分)

- **电商带货模块**:**9:16 / 1:1 / 16:9**(3 种)
- **智能视频模块**:**9:16 / 16:9 / 4:3 / 3:4**(4 种)

| 画幅 | 模块 | 适用平台 |
|---|---|---|
| **9:16** | 两模块都有 | 抖音 / 视频号 / 快手 / 小红书 视频帖 |
| **16:9** | 两模块都有 | B 站 / YouTube / 公众号视频 |
| **1:1** | 仅电商带货 | 商品主图视频 / 朋友圈 / 信息流 |
| **4:3** | 仅智能视频 | 淘宝详情页 |
| **3:4** | 仅智能视频 | 京东详情页 / 小红书图文混排 |

### 4.2 商用数字人

- 多形象库可选
- **多方言配音**
- **唇形同步算法**,画面与配音对齐
- 产出明确可商用

适合:**老板没空真人出镜的小商家** / 多账号矩阵号需要差异化数字人。

### 4.3 千万级版权素材库

AI 自动匹配画面 / 转场 / 背景音 / 字幕样式。**所有素材已购版权**,产出零版权风险。

### 4.4 首页 10+ 条真实演示案例

演示站首页挂着一批真实成片,每条都可以"复刻 prompt"。完整列表见 [`../examples/prompts.md`](../examples/prompts.md)。

## 五、典型工作流

### 工作流 1 · 单 SKU 带货视频

```
商品名 "复古黄铜壁灯 · 工业管道造型" + 商品主图
   ↓ (没有 prompt 输入框,直接提交)
[电商带货模块 · Agent 端到端]
   ↓
60 秒后 → 15/30 秒 9:16 / 1:1 / 16:9 带货成片
   ↓
下载 mp4 → 抖音 / 视频号 / 小红书 上传
```

**单 SKU 端到端 < 2 分钟**(含下载上传)。

### 工作流 2 · 矩阵号日产 50 条

```
运营批量提交 50 个 SKU(商品名 + 主图)
   ↓
电商带货模块并发跑
   ↓
50 条带货成片 → 全部下载
   ↓
分发到 12 个矩阵号(差异化分配)
```

### 工作流 3 · 节日营销批量出货

```
节日主题 "元宵节" + 各品类商品图
   ↓
智能视频模块(一句话):"元宵节夜晚红灯笼下汤圆碗特写,毛笔字浮现,温暖橘黄色调,节日氛围广告片,9:16 竖屏"
   ↓
不同品类各出一条节日营销片
   ↓
铺所有矩阵号
```

- 60 秒级 AI 出片
