# 首页真实成片案例库

> 演示站首页挂着 10+ 条真实成片案例。每条都可以"用同样提示词生成"一键复刻到智能视频模块。这里整理出来供改写参考。

**重要区分**:

- **电商带货模块**:**不需要 prompt**。只填商品名 + 主图,Agent 端到端自动。
- **智能视频模块**:需要一句话 prompt。本文档列的就是智能视频模块可用的 prompt。

---

## 一、电商带货模块 · 输入参考(不是 prompt!)

电商带货模块**输入字段只有两个**:商品名 + 商品主图。**不需要 prompt**。

但商品名的写法对 Agent 抽特征影响很大,**好的商品名写法**:

| ❌ 不好的商品名 | ✅ 好的商品名 |
|---|---|
| 壁灯 | 复古黄铜壁灯 · 工业管道造型 |
| 苹果干 | 减脂苹果干 · 0 添加糖 · 健身补给 |
| 皮衣 | 羊羔毛机车皮衣 · 棕色 · 秋冬款 |
| 包包 | 复古格纹双肩书包 · 校园风 |
| 益生菌 | 儿童益生菌软糖 · 橙色罐子 |
| 护肤管 | 暖色卧室护肤管 · 博主测评风 |

**公式**:`商品名 + 关键特征 + 场景调性`。Agent 端到端能从这种描述抽到足够特征。

商品主图建议白底处理(rembg / PS 抠白底),杂乱背景会干扰 Agent 抽特征。

## Prompt 写作要点(智能视频模块)

1. **先画面后台词**:画面要素 → 镜头语言 → 配音文案 / 字幕
2. **必带平台调性词**:`9:16 抖音种草风` / `杂志感构图` / `母婴号风格` / `测评风格` / `vlog`
3. **加光线描述**:`柔和顶光` / `逆光` / `胶片颗粒感` / `自然氛围`
4. **加运镜词**:`慢推近` / `环绕运镜` / `定格特写` / `低角度仰拍`
5. **加情绪 / 反差**:`捂肚子苦恼` / `开心展示` / `叹气下一秒...` / `回眸轻笑`
